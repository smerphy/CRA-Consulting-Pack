# Corrections to pack files from the OJ verification (E6)

Status: proposed edits only. E6 has not changed any file outside `pack/enterprise/oj-verification/`. Each entry gives the file, the exact text to find and the replacement. Every "old text" string below was matched against the file on 1 Nov 2026; where it occurs more than once the count is shown. Claim IDs refer to `claims.csv`.

Legal source for every change: Regulation (EU) 2024/2847 as published in OJ L, 2024/2847, 20.11.2024 (Publications Office cellar, English PDF/A-2a edition and XHTML), with the English corrigenda OJ L, 2024/90780 (5.12.2024), OJ L, 2025/90555 (2.7.2025) and OJ L, 2025/90828 (17.10.2025).

## How to apply

1. Apply Priority 1 before the next client issue of the knowledge base or the Templates Kit. These change what a reader would do.
2. Apply Priority 2 in the same release where practical. These fix quotations and citations.
3. Apply Priority 3 to remove caveats that the OJ check has now resolved.
4. Edit the source files, then regenerate or patch the derived copies listed under "Propagation". `pack/data/pack_data.json` is generated by `pack/engine/build.py`; edit the builder and rebuild rather than editing the JSON by hand.
5. After applying, re-run `grep` for each old string across the repository; the expected count is zero outside `research_notes/` and this module.
