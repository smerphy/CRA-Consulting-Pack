Illustrative · 20

Here is the T200 reference walk-through on one page. Boundary: the device, two apps and two cloud modules, with the weather API treated as a component. Class: heating control matches no Annex III category, so default class and Module A, re-checked if a camera or door sensor is ever added. Risk: BSI structure with STRIDE; every item applies except the transfer half of (m). Controls: per-unit codes, a fused UART, signed commands and local heating when the cloud fails. Release: SAST, parser fuzzing, API testing and a gate record per release. SBOMs and updates: signed, monitored SBOMs, TUF metadata and A/B slots. Reporting: telemetry on the replay flaw showed probing but no successful exploitation, so the incident commander recorded no awareness and no report was filed; the fix then shipped with a CSAF advisory. Documentation: one family file. This is the target state, not today’s status.
