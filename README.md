# CRA Readiness Programme Pack

White-label EU Cyber Resilience Act (Regulation (EU) 2024/2847) consulting pack, populated with an illustrative fictional client (Example Group, "Project Rampart"). Regulatory facts verified to 30 Oct 2026; notified-body status to 8 Sep 2026.

## Layout
- `pack/data/` — single source of truth (`pack_data.json`, `DATA_SUMMARY.md`); regenerate with `pack/build_data.py`
- `pack/BRIEF.md`, `pack/briefs/` — master brief and per-deliverable briefs (D01–D11, design system, QA)
- `pack/out/excel/` — business case / cost model and obligations register / programme tracker (.xlsx)
- `pack/out/portal/`, `pack/out/diagnostic/` — portal and readiness diagnostic HTML sources
- `pack/out/urls.json` — published artifact links (decks, comms pack, research report, surveys, dashboard, design system)
- `reports/` — CRA knowledge base (sections, corporate and application implementation guides, verification log)
- `research_notes/` — raw research notes

All client figures are illustrative. Not legal advice.
